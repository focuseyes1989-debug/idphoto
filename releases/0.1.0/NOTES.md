First signed Windows release of ID Photo Studio.

- Multi-photo editing with crop, resize, free rotation and local background removal.
- Levels, Curves and Selective Color adjustments.
- Mixed-photo sheets, paper sizes, margins, DPI, quantities and native printing.
- PNG Save/Save As and self-contained editable projects.
- Signed online updates from GitHub Releases.

Install the x64 setup executable once. Future versions can be installed through Help > Check for Updates.
