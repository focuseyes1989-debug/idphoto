ID Photo Studio 0.1.4

- Automatically split mixed photo quantities across multiple sheets.
- Scroll all sheets in the canvas and Print dialog, with zoom, drag and Fit to canvas.
- Show prepared canvas previews immediately and cache unchanged print previews.
- Link/unlink photo quantities and set separate column and row spacing.
- Add Undo, Redo, Copy, Cut and Paste with editable history.
- Disable sheet preview when no photos are open; refine panel alignment.
- Fix Print dialog refresh/reopen failures and Ctrl+P access.

Print and export retain full resolution. Multi-sheet exports use a ZIP of PNG pages.
